Настройка Callback API ВКонтакте (схема: nginx → порт 3000, Next.js)
====================================================================

У большинства продакшен-сборок так:
  • nginx принимает HTTPS и отдаёт всё на 127.0.0.1:3000 — там Next.js (pm2: «npm run start» и т.п.).
  • Логика Callback из этого репозитория живёт в server.cjs — его нужно держать отдельным процессом на внутреннем порту (ниже пример: 8765), НЕ занимая 3000.

ВК шлёт POST на: https://ваш-домен.ru/api/vk/callback
События: confirmation (подтверждение URL), message_new (сообщения в ЛС).

-------------------------------------------------------------------------------
1) Переменные окружения для процесса server.cjs (второй pm2 или отдельный .env)
-------------------------------------------------------------------------------
  VK_BOT_TOKEN=...
  VK_CALLBACK_CONFIRMATION=fe17a41e          (строка из кабинета ВК, как есть)
  VK_CALLBACK_SECRET=...                     (секрет из кабинета ВК, если включён)
  PORT=8765                                    (внутренний порт, не 3000)

Пример второго процесса:
  PORT=8765 pm2 start server.cjs --name altdi-api --update-env
  pm2 save

-------------------------------------------------------------------------------
2) Главный способ при «всё на 3000»: прокси внутри Next.js
-------------------------------------------------------------------------------
  Next на 3000 должен пересылать POST /api/vk/callback на server.cjs.

  • Скопируйте файл doc/nextjs-proxy-vk-callback-route.ts в проект Next как:
      src/app/api/vk/callback/route.ts
  • В .env у Next.js (тот, что читает при build/start):
      MEDIA_SERVER_URL=http://127.0.0.1:8765

  Пересоберите и перезапустите Next:
      npm run build
      pm2 restart <ваш-процесс-next>

  Секреты VK_* должны быть в .env процесса server.cjs (altdi-api), не обязательно в Next.

-------------------------------------------------------------------------------
3) Альтернатива без правок Next: исключение только в nginx
-------------------------------------------------------------------------------
  Если не хотите добавлять route в Next — один location раньше общего proxy на 3000:

      location = /api/vk/callback {
          proxy_pass http://127.0.0.1:8765;
          ...
      }
      location / {
          proxy_pass http://127.0.0.1:3000;
          ...
      }

  Подробнее см. doc/nginx-vk-callback-snippet.conf

-------------------------------------------------------------------------------
4) Проверка до нажатия «Подтвердить» в ВК
-------------------------------------------------------------------------------
  curl -sS -w "\nHTTP:%{http_code}\n" -X POST "https://altdi.ru/api/vk/callback" \
    -H "Content-Type: application/json" \
    -d '{"type":"confirmation","group_id":238093187}'

  Нужно: тело ровно строка подтверждения (например fe17a41e), HTTP 200.
  Если HTML или 404 — запрос доходит в Next без прокси или nginx не туда.
