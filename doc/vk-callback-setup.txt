Настройка Callback API ВКонтакте для ответа на «Старт» / «start»
================================================================

1. Управление сообществом → Настройки → Работа с API → Callback API.
2. URL сервера: https://altdi.ru/api/vk/callback  (или ваш домен + путь)
3. Версия API: 5.199 (или актуальная, как в VK_API_VERSION).
4. Событие: входящее сообщение (message_new).

Переменные окружения на сервере (.env):

  VK_BOT_TOKEN=...              (токен сообщества с правом messages)
  VK_CALLBACK_CONFIRMATION=...  (строка подтверждения из настроек Callback в ВК)
  VK_CALLBACK_SECRET=...        (опционально: тот же «Секретный ключ», что в ВК)

После сохранения ВК отправит запрос type=confirmation — сервер вернёт VK_CALLBACK_CONFIRMATION.

Пользователь: кнопка на сайте ведёт на https://vk.com/altdiru , первое сообщение — Старт/старт/Start/start.
